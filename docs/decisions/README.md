# Architecture Decision Records

ADRs explain structural decisions and their rationale. The linked operational documents remain
the normative source for details; ADRs do not duplicate them.

| [ADR-003](003-systems-of-record.md) | Divide authority among the integrated systems |
| [ADR-004](004-agentic-tool-adapters.md) | Use a neutral protocol for agentic tools |
